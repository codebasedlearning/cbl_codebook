# C++ samples — Codebook

A standalone CMake project. Open this folder in CLion (it is a project root of
its own) or run the snippets from the IDE.

## What the plugin reads here

- `cbl.properties` — codebook properties
- `docs/glossary.md` — C++ glossary; headings are the referenceable blocks
- `docs/answers.md` — answers to the question blocks
