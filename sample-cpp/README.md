# C++ samples — Codebook

A standalone CMake project. Open this folder in CLion (it is a project root of
its own) or run the snippets from the IDE or the command line:

```bash
cmake -B cmake-build-debug
cmake --build cmake-build-debug
./cmake-build-debug/staticmethod     # static members: the kinds, side by side
```

## What the plugin reads here

- `cbl.properties` — `glossary.path`, and the fully documented reference for
  every other key
- `doc/glossary.md` — C++ glossary; headings are the referenceable blocks
- `doc/answers.md` — answers to the question blocks
