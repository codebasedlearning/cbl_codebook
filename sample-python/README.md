# Python samples — Codebook

A [uv](https://docs.astral.sh/uv/) project. Open this folder in PyCharm (it is a
project root of its own) or run the snippets from the IDE or
the command line:

```bash
uv run snippets/staticmethod.py     # static methods: the three kinds, side by side
```

## What the plugin reads here

- `cbl.properties` — `glossary.path`
- `glossary.md` — Python glossary; headings are the referenceable blocks
- `answers.md` — answers to the question blocks
